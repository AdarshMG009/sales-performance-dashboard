## Overview
This project analyzes sales data using Excel to identify key business insights.

## Tools Used
- Excel
- Pivot Tables
- Charts
- Slicers

## Key Insights
- Laptop is top-performing product
- North region generates highest revenue
- Sales drop observed in some months

## Recommendations
- Focus on high-performing products
- Improve low-performing months
- Target key regions
